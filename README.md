# 👑 Loki: The God of Stories 3D (Snowman Edition)
> *"I want you to know that I'm never leaving..."* — Sia

เว็บเกมมีม **"โลกิเดอะแบกแห่งกาลเวลา 3D" (Full WebGL 3D Interactive Experience)** พัฒนาด้วย Three.js จำลองฉากไคลแมกซ์ของ Loki Season 2 ที่ต้องรวบรวมเส้นเวลากาลเวลาลากขึ้นสู่บัลลังก์ทองคำ Citadel เพื่อถักทอเป็น **ต้นไม้อิกดราซิล 3 มิติ**

---

## 🌟 ฟีเจอร์ 3D เต็มรูปแบบ (Production-Ready 3D):
1. **Real-Time 3D Environment:**
   * บันไดหิน Citadel 3 มิติ 40 ขั้น ทอดยาวสู่อวกาศควอนตัม
   * อุกกาบาตหินออบซิเดียนลอยเคว้งคว้างและหมุนรอบฉากแบบ 3D
   * บัลลังก์ทองคำ 3D (The Golden Throne) ที่มีแสงวอลูเมตริกสีทองส่องสว่างลงมา
   * กล้อง 3D Cinematic Camera เคลื่อนที่ตามหลังและข้างลำตัวโลกิอย่างนุ่มนวล

2. **3D Character Rig & แอนิเมชันสมจริง:**
   * แอนิเมชันการเดินและออกแรงดึง (Procedural Walking & Straining Cycle) ขาและหัวเข่าขยับก้าวจริง
   * ผ้าคลุม 3D สะบัดตามลมด้วย Dynamic Cloth Simulation
   * มงกุฎเขาทองคำ 3D สะท้อนแสงเมทัลลิก ปรับแต่งทรงเขาได้ 4 รูปแบบ
   * ป้ายชื่อ 3D ลอยเด่นเหนือหัวโลกิตามชื่อที่คุณกรอก

3. **ฟิสิกส์เส้นเวลา 3D (Cable Physics & Sparks):**
   * สายเคเบิลกาลเวลา 3D มหึมาหลายสายเชื่อมจากมือโลกิลากครูดไปตามขั้นบันไดหิน
   * สะเก็ดไฟ 3D (Friction Sparks) กระเด็นออกจากจุดที่สายเคเบิลสัมผัสหิน
   * แรงดึงย้อนกลับ (Multiverse Resistance) ถ้าหยุดออกแรง มวลของเส้นเวลาจะดึงคุณไถลถอยหลัง

4. **ฉากจบ 3D มหากาพย์ (Grand 3D Yggdrasil Transformation):**
   * กิ่งก้านต้นไม้อิกดราซิล 3D ขนาดมหึมาจะแตกแขนงพุ่งขึ้นสู่ท้องฟ้าจักรวาล โอบล้อมบัลลังก์ทองคำไว้ พร้อมสะเก็ดดาวสีทอง

## 🎮 วิธีการเล่น:
- **แตะปุ่ม PULL! รัวๆ (หรือกด Spacebar / ลูกศรขวา):** ออกแรงดึงก้าวเดินขึ้นบันได
- **รักษาแรงดึง:** อย่าปล่อยให้แถบแรงตึงพุ่งถึง 100% ไม่งั้นจะโดนลากตกบันได
- **เป้าหมาย:** เดินให้ครบ 100 เมตรเพื่อขึ้นนั่งบนบัลลังก์ทองคำและปลดล็อกต้นไม้ 3D!

## 🚀 วิธีอัปเดตขึ้น GitHub Pages:
1. เข้าเว็บ [github.com](https://github.com) ไปที่ Repository ของคุณ (`loki-yggdrasil`)
2. กด **Add file** > **Upload files**
3. ลากไฟล์จากโฟลเดอร์ `myfdt` ทับลงไป:
   - `index.html`
   - `style.css`
   - โฟลเดอร์ `js`
   - `loki.html`
   - `README.md`
4. กด **Commit changes** รอ 1 นาที แล้วเปิดลิงก์เดิมเล่นได้ทันที!
