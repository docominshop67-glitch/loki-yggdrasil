- **Visuals ระดับ Cinematic:** โลกิพร้อมมงกุฎเขาทองคำ (God of Stories Horns), เสื้อโค้ตสะบัดตามลม, มือเปล่งแสงเวทย์สีเขียวมรกต
- **Rope & Vine Physics:** ระบบฟิสิกส์เส้นด้ายที่แกว่งไหว ย้วยตามแรงเดิน และมีชีพจรแสงวิ่งตามสาย
- **Meme Tags:** ป้ายมีมลอยตามสายกาลเวลา เลือกธีมได้:
  - 🏠 **ชีวิตจริง:** การนอน 8 ชม., สุขภาพจิต, เงินในบัญชี, ความหวัง
  - 💻 **คนทำงาน:** Legacy Code, Deadline พรุ่งนี้, แก้งานรอบที่ 8, บอส
  - 🎓 **เด็กมหาลัย:** โปรเจกต์กลุ่ม, สอบไฟนอล, งานเดี่ยวที่ทำคนเดียว
  - ⚡ **Marvel Lore:** Sacred Timeline, Earth-616, Kang, Mobius Jet-Ski
- **เพลง Snowman (Sia):** มีระบบ Web Audio สังเคราะห์เมโลดี้เพลง Snowman ในตัวทันที และรองรับไฟล์ `snowman.mp3` ถ้าอยากได้เสียงร้องต้นฉบับ
- **รองรับ Mobile Touch 100%:** เล่นบนมือถือ Android / iOS ได้ลื่นไหล 60 FPS

## 🚀 วิธีเอาขึ้น GitHub Pages (เล่นบนมือถือฟรีตลอดกาล)

1. **สร้าง Repository ใหม่บน GitHub:**
   - ไปที่ [github.com/new](https://github.com/new)
   - ตั้งชื่อ Repository เช่น `loki-yggdrasil`
   - เลือกเป็น **Public** แล้วกด **Create repository**

2. **เปิดโฟลเดอร์นี้ใน Terminal / Git Bash:**
   ```bash
   git init
   git add .
   git commit -m "Initial Loki Yggdrasil Snowman meme game"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/loki-yggdrasil.git
   git push -u origin main
   ```

3. **เปิดใช้งาน GitHub Pages:**
   - ไปที่แท็บ **Settings** ใน Repository ของคุณ
   - เลื่อนไปที่เมนู **Pages** (แถบซ้ายมือ)
   - ตรงส่วน **Build and deployment > Branch** ให้เลือก `main` และ `/ (root)` แล้วกด **Save**
   - รอประมาณ 1 นาที จะได้ลิงก์ เช่น `https://YOUR_USERNAME.github.io/loki-yggdrasil/` ส่งให้เพื่อนเล่นในมือถือได้ทันที!
